# IoT Telemetry NoSQL Lab — Dashboard Edition

A local Streamlit dashboard for demonstrating MongoDB telemetry data, CRUD operations, complex aggregation pipelines, indexing, explain plans, and sharding-status checks.

## Features
- Overview with KPI cards, event-type chart, temperature summaries, and latest readings
- Telemetry Explorer with filters, readable tables, CSV export, insert/update/delete forms
- Aggregation Lab with eight MongoDB aggregation examples and pipeline viewer
- Performance & Sharding page for indexes, `explain()`, and router-status checks
- Synthetic sample-data generator for a repeatable demo

Read `RUN.md` to start the application. Read `EXPLANATION.md` for viva guidance and `SHARDING.md` for actual cluster setup notes.
